# Moved to openctemio/openctem

The OpenCTEM web UI now lives in **[openctemio/openctem](https://github.com/openctemio/openctem)**, directory [`web/`](https://github.com/openctemio/openctem/tree/develop/web), together with the API (`api/`).

This repository is **archived and read-only**. Its full history was imported into `openctemio/openctem`, and its release tags are there as `ui/v*` (for example `ui/v0.8.0`).

Open issues and pull requests against [openctemio/openctem](https://github.com/openctemio/openctem).
